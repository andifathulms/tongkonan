## Design Specificity Verdict

Authored, unmistakably — closed pa'ssura palette with documented ratios, surveyor's-sheet layout, computed silhouettes as UI furniture, provenance as the emotional centre. Nothing category-interchangeable. The weaknesses are scale-of-35 weaknesses, not genericism: the wayfinding was composed for 4 houses and now carries 35.

Deterministic scan: detect.mjs over app/ and components/ returned zero findings (exit 0). No false positives to flag. Browser overlays skipped: no browser automation in this session.

## Priority Issues

1. [P1] No findability apparatus at 35 — landing renders shelf, map, and index as three complete enumerations (~105 links to 35 places), ordered by registry-join history; no search, filter, or region grouping. Teacher/student personas pay a full scan per visit. Fix: group by island/region (data exists as t.place/t.site), add type-to-filter, one enumeration per breakpoint. → shape
2. [P1] Site map is desktop-only in practice — plaques are :hover/:focus CSS (page.tsx:397), never fire on touch; glyph hit targets ~12×8px on a phone, under the project's own 24px floor. Fix: region list below sheet breakpoint; tap-to-reveal then navigate; enlarged invisible hit rects. → adapt
3. [P1] Every viewport announces itself as a tongkonan to AT — Viewport.tsx:329 uses hardcoded COPY.modelLabel ("Model tongkonan…") for all 35 traditions, violating the neutrality contract in the one layer the architecture tests cannot see. Fix: thread tradition.house[locale] into the label. → clarify
4. [P2] No way back to the default house — changed rules are unrecoverable without URL surgery, and an untouched page never writes its default query, so a copied address is not the promised complete description. Fix: reset-to-canon control + write full query on settle. → harden
5. [P2] Entrance choreography doesn't scale — house-raise staggers 35 × 150ms ≈ 5.5s on landing and 404; the last houses pop in after the reader has scrolled. Fix: stagger per row or compress within the 1100ms orchestrated budget. → animate

## Persona Red Flags

- Jordan (first-timer): plate numbers ("Lembar T-14") imply an order never explained; shelf's primary nav links are 11px mono micro-labels; /sumber counterexample section arrives before sources with no bridge.
- Casey (mobile): map taps navigate blind to unnamed destinations; shelf pans with half the collection off-screen; single-column ~10,000px index with the anchor nav hidden below sm:.
- Sam (AT): the modelLabel leak (worst in app); landing has no skip link and ~105 sequential links; working routes otherwise exemplary (Choice radios, aria-valuetext, two-ring focus).
- Bu Ratna (teacher, classroom projector): micro/meta layer (11–13px) illegible from the back row; no region axis to find "rumah adat Kalimantan"; no side-by-side comparison, the natural lesson structure; 704KB landing HTML heavy on mobile data. Citation flow itself is best-in-class.

## Cognitive Load

2 hard failures + 2 partials (moderate-to-high, all at collection scale): the landing presents the identical 35-way decision three times; /bangun rail stacks ~8 sections; comparing houses requires holding figures in working memory across the up-and-back-down switch.

## What's Working

1. The honesty layer is a designed object — provenance bar with reserved columns, rara spent only on arguments, the counterexample panel.
2. Address-as-citation is real IA — path/query/fragment split, old paths answering, stage names in shared links.
3. Accessibility craft above almost any production site — documented ratios, complete reduced-motion alternatives, one-rule two-ring focus.

## Questions to Consider

1. What if the landing said each thing once — map as index on desktop, grouped list on phones, shelf as hero?
2. Is the classroom's unit of reading one house or two? Side-by-side adjacency violates no principle and might fulfil "no tradition wears another's shape" louder than any single view.
3. Who are the 11px labels for — the drawing register, or a desk-distance assumption the projector audience breaks?
